# Hushaboom

Noise generator - white, pink, and brown noise plus synthesized ocean
waves, wind, rain, and rustling trees: a dependency-free SwiftPM library
(`NoiseKit`) and a SwiftUI mixer app for iOS 15+ and macOS 12+.

Every nature sound is synthesized, not sampled - nothing loops, so there
is no seam to hear. Each has perceptual sub-parameters (`OceanParameters`,
`WindParameters`, `RainParameters`, `TreesParameters`) settable live
through `NoisePlayer`.

## Layout

- `NoiseKit/` - standalone SwiftPM package: generators, spectral tests, and
  an `AVAudioEngine`-based `NoisePlayer` that mixes all colors with
  independent, click-free smoothed levels.
- `App/` - shared SwiftUI sources for the iOS and macOS app targets, plus
  `PrivacyInfo.xcprivacy` (declares the `UserDefaults` required-reason API)
  and the generated macOS entitlements. The `Info-*.plist` and
  `*.entitlements` files there are generated by XcodeGen; edit `project.yml`.
- `Design/` - app icon work: `icon-brief.md` (design spec and Icon Composer
  requirements), `generate-icon.py` (generates the artwork; it is the source
  of truth, not the SVGs), and `icon/` (import-ready layered SVGs).
- `Hushaboom.icon` - Icon Composer document; both app targets reference it by
  name. Regenerate its source layers with `Design/generate-icon.py`.
- `website/` - [Middleman](https://middlemanapp.com) site for
  hushaboom.burns.io (the App Store support and privacy-policy URLs).
  GitHub Actions builds and deploys it; the build output is not committed.
- `project.yml` - [XcodeGen](https://github.com/yonaskolb/XcodeGen) spec that
  produces `Hushaboom.xcodeproj` (the project file is generated, don't edit it
  by hand).

## Building

```sh
brew bundle        # xcodegen + fastlane
make setup         # generate the project, check signing credentials
make help          # all targets

make run           # build and launch on macOS
make run-simulator # build, install, and launch on IOS_SIMULATOR
make run-ios       # build, install, and launch on IOS_DEVICE
make test          # NoiseKit suite (~5 min; the spectral tests are slow)
```

`Hushaboom.xcodeproj` is generated from `project.yml` and is not checked in;
`make generate` (or any build target) recreates it.

## Screenshots

```sh
make screenshots        # iPhone, iPad, and macOS
make screenshots-ios    # fastlane snapshot
make screenshots-mac    # XCUITest, exported from the result bundle
```

Output lands in `fastlane/screenshots/` (gitignored). Both platforms share
`UITests/ScreenshotFixtures.swift`, which injects a fixed mix through the
UserDefaults argument domain so the captures are identical run to run.

Two things to know before editing them:

- Fixture values must be plist fragments (`<real>0.65</real>`). The argument
  domain treats a bare `0.65` as a string, `as? Double` returns nil, and every
  slider silently falls back to its default.
- Never start the sleep timer in a screenshot. Its label is a live
  `Text(_, style: .timer)` counter, so the image would differ every run.

The screenshot tests live in their own test plans, so `xcodebuild test` on
either app scheme runs zero tests rather than booting simulators.

## Releasing

`CFBundleShortVersionString` comes from `MARKETING_VERSION` in `project.yml`.
`CFBundleVersion` comes from `CURRENT_PROJECT_VERSION`, which every build
target overrides with a date-derived `BUILD_NUMBER` (`2026.257.14`) so it
always increases without any state to track.

```sh
make install-key SRC=~/Downloads/AuthKey_XXXXXXXXX.p8   # one time
make archive-ios    # or archive-mac, for a local release archive
make beta           # build and upload both platforms to TestFlight
```

Credentials live in `.env` (gitignored; see `.env.example`) - the App Store
Connect key id, issuer id, and the path to the `.p8`. The key is shared across
every app on the team, so it lives at
`~/.appstoreconnect/private_keys/` rather than inside this repo.

## Website

`website/` is a Middleman app that produces hushaboom.burns.io.

```sh
cd website && bundle install   # one time
make watch                     # dev server on :4567
make build                     # writes website/build
```

`.github/workflows/pages.yml` builds and deploys it to GitHub Pages on any
push to `main` that touches `website/`, so the build output is not committed.
The domain comes from `website/source/CNAME`.

`Gemfile.lock` must list `x86_64-linux` alongside the local platform or the
CI build fails to resolve; after changing gems run:

```sh
cd website && bundle lock --add-platform x86_64-linux
```

## Installing on a device

1. In Xcode > Settings > Accounts, sign in with an Apple ID (free works;
   apps expire after 7 days and are limited to 3 sideloaded at a time).
2. Put your team ID into `DEVELOPMENT_TEAM` in `project.yml` and rerun
   `xcodegen generate`, or pick the team once in the target's Signing pane.
3. On the device, trust the developer certificate under
   Settings > General > VPN & Device Management.

Deployment target is iOS 15.0, so it runs on everything back to an
iPhone 6s/7 on iOS 15.

## NoiseKit API

```swift
import NoiseKit

var pink = PinkNoiseGenerator()          // or .pink.makeGenerator()
let sample = pink.nextSample()           // one Float in [-1, 1]

let player = NoisePlayer()               // AVAudioEngine mixer playback
player.setLevel(0.8, for: .brown)        // each color has its own level
player.setLevel(0.3, for: .pink)         // smoothed ~30 ms, no zipper noise
player.setLevel(0.6, for: .ocean)
player.oceanParameters = OceanParameters(wavePeriod: 0.7, waveHeight: 0.9, tone: 0.2)
try player.start()
player.volume = 0.5                      // master volume
player.stop()
```

`OceanParameters` also has a raw-field initializer (typical wave interval
and its per-wave variation, bed/swell balance, carrier blend, crash
brightness) when the four macros aren't enough. The player restarts itself
after engine reconfigurations, iOS interruptions, and media daemon resets,
and stops when the output device it was using goes away (headphones
unplugged); `onPlaybackStateChange` reports recoveries, that stop, and
final failures.

All colors are normalized to the same RMS (-14 dBFS) so mixing levels are
comparable. Generators are seedable and deterministic for a fixed seed.
